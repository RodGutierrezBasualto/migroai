# Migro — Brand & Marketing Guidelines

> Intelligent Intake for Migration Agents. Made in Australia.

---

## 1. Brand Identity

### Brand Name
**Migro** — always capitalised, never "MIGRO" or "migro."

### Tagline
**"Intelligent Intake for Migration Agents."**

### Positioning Statement
Migro is an AI-powered client intake and visa pathway assessment platform built exclusively for MARA-registered migration agents in Australia. It replaces manual, time-consuming intake with a branded chatbot that qualifies leads, collects documents, and assesses visa pathways — before the agent picks up the phone.

### Logo
- **Mark:** Rounded square (8px radius) in Forest green containing a white diamond/arrow motif — two overlapping chevrons suggesting forward movement and pathways
- **Wordmark:** "Migro" in Fraunces (display serif), semibold, tight tracking
- **Minimum clear space:** Equal to the height of the logo mark on all sides
- **On light backgrounds:** Forest mark + Forest wordmark
- **On dark backgrounds:** `white/10` mark + `white/60` wordmark

### Font Families

### Why These Fonts
- **Fraunces** is a soft, expressive serif that adds personality and warmth to headings without feeling corporate or clinical. Its variable optical sizing adapts well across the full scale from massive hero headlines to small card titles.
- **DM Sans** is clean, legible, and geometric — a functional counterpoint that keeps UI text, labels, and body copy neutral and scannable.

## 5. Voice & Tone

### Brand Voice Attributes

| Attribute | What it means | What it doesn't mean |
|---|---|---|
| **Authoritative** | We know Australian immigration law and the MARA ecosystem deeply | Stiff, academic, or condescending |
| **Direct** | We get to the point; no filler, no jargon for jargon's sake | Blunt, cold, or dismissive |
| **Confident** | We believe in the product and say what it does plainly | Hyperbolic, pushy, or salesy |
| **Professional** | We speak as a peer to MARA agents, not a generic SaaS vendor | Corporate-speak, buzzword-heavy |
| **Warm** | We're helpful, human, and approachable underneath the expertise | Overly casual, jokey, or informal |

### Tone by Context

| Context | Tone | Example |
|---|---|---|
| **Headlines** | Bold, concise, slightly provocative — one punchy sentence | "The old way doesn't scale." |
| **Section descriptions** | Informative, conversational, second-person ("you", "your") | "Manual intake is the silent bottleneck in every migration firm." |
| **Feature copy** | Benefit-led, specific, active voice — what Migro *does* for the agent | "Migro's AI analyses each client's data against Australian immigration legislation..." |
| **CTAs** | Action-oriented, low-friction, no pressure | "Join the Waitlist", "See how it works", "Get Started Free" |
| **Small print / legal** | Transparent, plain, no hedging | "No spam. Unsubscribe anytime. We respect your privacy." |
| **Security / compliance** | Factual, specific, credential-heavy — cite the standard, name the law | "Privacy Act 1988 (Cth) · Australian Privacy Principles enforced." |
| **Error states** | Calm, helpful, no blame | "Something went wrong — please try again." |

### Writing Rules

1. **Use Australian English** — "colours" not "colors", "organisation" not "organization", "licence" (noun)
2. **Address the agent directly** — "your practice", "your clients", "your website"
3. **Lead with the outcome** — not the feature. Say what changes for the agent, then how.
4. **Use specifics** — "15–30 minutes per prospect", "Subclass 186", "AES-256", not vague claims
5. **One idea per sentence** — short, punchy sentences. Break long thoughts across lines.
6. **Avoid generic SaaS language** — no "leverage", "empower", "revolutionise", "seamless", "cutting-edge"
7. **Name Australian legislation** — Privacy Act 1988, Migration Act 1958, MARA Code of Conduct. This audience respects specificity.
8. **Use en-dashes for ranges** — "15–30 minutes", not hyphens
9. **No exclamation marks in body copy** — let the message carry the weight
10. **Sentence case for headings** — "Simple, transparent pricing." not "Simple, Transparent Pricing."

## 6. Copy Architecture

### Page Flow (Narrative Arc)

The page follows a **problem → solution → proof → action** structure:

| # | Section | Narrative Role | Emotional Beat |
|---|---|---|---|
| 1 | **Hero** | Hook — state the value proposition in one breath | Curiosity, recognition |
| 2 | **Dashboard** | Show, don't tell — live interactive demo of the agent's view | "I can see myself using this" |
| 3 | **Waitlist** (early) | First CTA — capture high-intent visitors before they scroll further | Urgency, exclusivity |
| 4 | **Features** | Deep dive — three core capabilities with visual mockups | Understanding, confidence |
| 5 | **How It Works** | Simplify — three-step process that makes adoption feel easy | Relief, "this is doable" |
| 6 | **Credibility Strip** | Trust — security, compliance, certifications, ASD partnership | Safety, legitimacy |
| 7 | **Footer** | Close — minimal, confident | Resolution |

### Headline Inventory

| Section | Headline | Technique |
|---|---|---|
| Hero | "Intelligent Intake **for Migration Agents.**" | Benefit + audience in one line; accent color on audience |
| Dashboard | "Your entire practice, in one view." | Possession ("your") + scope |
| Waitlist | "Be first to transform your practice." | Urgency + aspiration |
| Features | "Everything you need, nothing you don't." | Contrast/balance |
| How It Works | "Live in minutes. Saving hours from day one." | Time contrast — minutes vs. hours |
| Problem | "The old way doesn't scale." | Provocation, challenge the status quo |
| Credibility | "Built secure. Compliant by design." | Two short declarative phrases, parallel structure |
| Pricing | "Simple, transparent pricing." | Trust signal — addresses a common objection |

### Recurring Copywriting Patterns

- **Time contrast:** "in seconds, not hours", "live in minutes, saving hours", "before you pick up the phone"
- **Quantified pain:** "Up to 70% of inquiries never qualify", "15–30 minutes per prospect"
- **Second-person framing:** "your practice", "your website", "your clients", "your firm"
- **Dot-separated micro-labels:** "Coming soon · Built for MARA-registered agents", "Early access · Limited spots"
- **Dash-separated detail:** "AES-256 encrypted · Sydney region"
- **Compliance specificity:** Names exact legislation, subclasses, and standards rather than vague "we're compliant" claims

## 10. Motion & Animation

### Principles
1. **Purposeful, not decorative** — every animation communicates meaning (entry, state change, progress)
2. **Subtle and fast** — 0.25–0.6s durations, no bouncing or overshooting
3. **Scroll-triggered, fire-once** — elements animate in as they enter the viewport, then stay put
4. **Staggered for groups** — related items appear sequentially at 0.1–0.15s intervals

### Entry Animations (Framer Motion)

| Pattern | From | To | Duration | When Used |
|---|---|---|---|---|
| Fade up | `opacity:0, y:20` | `opacity:1, y:0` | 0.5s | Default for most elements on scroll |
| Slide right | `opacity:0, x:30` | `opacity:1, x:0` | 0.6s | Chat widget entrance |
| Scale in | `opacity:0, scale:0.95` | `opacity:1, scale:1` | 0.3s | Success states, assessment cards |
| Row slide | `opacity:0, x:-6` | `opacity:1, x:0` | 0.25s | Table rows, document lists |
| Progress fill | `width:0` | `width:X%` | 0.8s | Visa pathway confidence bars |

### CSS Animations

| Name | Duration | Easing | Use |
|---|---|---|---|
| Pulse slow | 4s | ease-in-out | Status indicator dots ("Online", active) |
| Marquee | 28s | linear | Scrolling text strip (defined, reserved) |
| Bounce | default | default | Typing indicator dots |
| Spin | default | default | Loading spinner |

### Typewriter Effect
- **Speed:** 28ms per character
- **Post-completion pause:** 600ms before next message
- **Used in:** Chat widget bot messages only

### Dashboard Auto-Cycle
The dashboard widget cycles through three screens automatically:
1. **Dashboard** → rows appear at 400ms intervals, hold 2.3s
2. **Detail** → assessment appears at 700ms, hold 2.5s
3. **Documents** → stat cards (200ms intervals) → doc rows (250ms intervals) → AI flags (500ms delay), hold 3.5s

### Section Spacing
- Standard vertical padding: **96px** (`py-24`)
- Large vertical padding: **112px** (`py-28`) — Waitlist section
- Heading-to-content gap: **56–64px** (`mb-14` to `mb-16`)

### Grid System
| Columns | Breakpoint | Gap | Use Case |
|---|---|---|---|
| 1 → 2 | `lg` (1024px) | 48–64px | Hero, Features (alternating) |
| 1 → 3 | `md` (768px) or `lg` | 24px | Problems, How It Works |
| 1 → 2 → 4 | `md` → `lg` | 20px | Pricing, Security pillars |

### Responsive Strategy
- **Mobile-first** — base styles are mobile; complexity added at breakpoints
- **Three breakpoints:** `sm` 640px, `md` 768px, `lg` 1024px
- Font sizes step up at `lg` (e.g. `text-4xl` → `text-5xl`)
- Hidden elements on mobile via `hidden sm:block`
- Dashboard sidebar collapses from labelled nav to dot indicators on mobile

## 13. Content Strategy & Messaging

### Target Audience
**MARA-registered migration agents in Australia** — solo practitioners and small-to-medium firms (2–10 agents). They are:
- Legally regulated professionals (registered with the Office of the MARA)
- Overwhelmed by administrative intake work
- Concerned about compliance (Privacy Act, Migration Act, MARA Code of Conduct)
- Cautious about AI — need reassurance on data sovereignty, privacy, and accuracy
- Time-poor — billing for casework, not for qualifying leads

### Key Messages (in priority order)

1. **Save time on intake** — Migro handles the first 15 minutes of every client relationship
2. **Only qualified leads reach you** — AI pre-qualifies and assesses visa pathways before you're involved
3. **Secure and compliant** — Australian data residency, AES-256 encryption, ASD partnership, MARA-aligned
4. **Live in minutes** — one line of code, fully branded, 24/7
5. **You stay in control** — Migro assists; the agent reviews, decides, and acts

### Proof Points Used

| Claim | Evidence |
|---|---|
| Trust & security | ASD Cyber Security Business Partner badge |
| Compliance | CSA STAR Level One, CSA STAR for AI Level One certifications |
| Infrastructure | Google Cloud Platform (ISO 27001, SOC 2 Type II, PCI DSS, IRAP) |
| Data sovereignty | "All data processed and stored exclusively within Australia" |
| Encryption | AES-256 at rest, TLS 1.3 in transit |
| AI privacy | "Zero data retention on AI inference. Your documents are never used to train AI models." |

### Objection Handling (implicit in copy)

| Objection | How the page addresses it |
|---|---|
| "Is my data safe?" | Credibility Strip: 4 security pillars, ASD badge, certifications |
| "Is this MARA compliant?" | Multiple references to MARA, Migration Act, Privacy Act |
| "Will AI replace me?" | Framing: "before you pick up the phone", "ready for your expert review" — AI assists, agent decides |
| "Is it hard to set up?" | "Live in minutes", "single line of code", 3-step How It Works |
| "How much does it cost?" | Free tier, transparent pricing, "subject to change at launch" honesty |
| "Can I trust a new product?" | Waitlist/early access framing builds exclusivity, not desperation |

## 17. Do's and Don'ts

### Do
- Use the Forest/Emerald palette consistently — no rogue blues or purples
- Write in Australian English with specific legislation references
- Address agents directly in second person
- Use warm green-tinted shadows, not black
- Keep animations subtle and under 0.8s
- Lead with outcomes, not features
- Use the serif (Fraunces) for headings only

### Don't
- Use Fraunces for body text or UI labels
- Use black (`#000000`) anywhere — Forest replaces it
- Use pure grey — Warm Grey has a warm yellow undertone by design
- Add exclamation marks to copy
- Use generic SaaS buzzwords ("leverage", "empower", "seamless")
- Overload with animations — one entrance animation per element
- Use icon libraries — maintain inline SVGs for consistency
- Show pricing without the AUD / GST / launch disclaimers
